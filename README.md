 RaceDay API

 Project Description
RaceDay is a web-based event management system for running, walking and cycling events. It allows users to register, log in, view events, enrol in events and track their performance.

 Technologies Used
- C#
- ASP.NET Core Web API
- SQL Server LocalDB
- Swagger

 Main Features
- User registration and login
- View user profiles
- View and manage events
- Manage event categories
- Enrol participants in events
- Track participant performance
- Manage event results

 Database
The project uses a SQL Server LocalDB database called `raceday`.

The database stores information about organisers, participants, events, categories, enrolments, performance and results.

 How to Run the Project
1. Open the project in Visual Studio.
2. Make sure the database is set up correctly.
3. Run the project.
4. Open Swagger in your browser.
5. Use Swagger to test the API endpoints.

Testing
The API endpoints can be tested using Swagger. The available operations include GET POST PUT and DELETE.
